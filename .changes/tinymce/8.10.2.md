## 8.10.2 - 2026-11-11

### Added
- New `getFullySelectedBlocks` function added to `tinymce.selection` which returns the blocks fully covered by the selection. #TINYMCE-14939

### Fixed
- A new line inside an indented TD prevented the `Decrease Indent` of the content. #TINYMCE-8693
- Image and table resize handles are now hidden from screen readers with `aria-hidden="true"`. #TINYMCE-14927
- Following an anchor link to a target inside a collapsed `details` element, such as a closed accordion, now expands it, as browsers do when navigating to an in-page link. #TINYMCE-14737
- Underline applied around subscript or superscript text was drawn at the baseline of the surrounding text instead of under the subscript or superscript text. #TINYMCE-15001
- Node positioned context toolbars repositioned above the editor when the node width was less than the toolbar. #TINYMCE-13900
- The image dialog got stuck on "Uploading image" when an empty or unreadable file was selected on the Upload tab. An error message is now shown and the dialog can be used again. #TINYMCE-7202
- Leaving a list with Enter copied the list item's styles onto the new paragraph. #TINYMCE-13035
- Long item text in dialog listboxes overflowed the dialog. #TINYMCE-14261
