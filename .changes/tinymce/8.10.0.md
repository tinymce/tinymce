## 8.10.0 - 2026-10-14

### Added
- Added the `BlobInfo` type to the public API. #TINYMCE-14853
- New `revert-all` icon. #TINYMCE-14851

### Fixed
- Applying a list style did not change the markers, and the toolbar showed the wrong active style, on list items that had their own inline `list-style-type`. #TINYMCE-14565
- Clicking to the right of a list item's text in an unfocused editor scrolled the content back to the top in Chrome. #TINYMCE-14856
- Drag selection wasn't working when clicking on the right of an `li` in Chrome. #TINYMCE-14855
- Resizing an image would sometimes show a 0px ghost image #TINYMCE-14887
- Clicking to the right of an `&nbsp;` at the end of an element could make the selection jump if there is an empty element inside the editor. #TINYMCE-14724
- Opening or closing a View no longer scrolls the editor to the caret position. #TINYMCE-14905
- The editor iframe was missing its `title` attribute on browsers other than Firefox. #TINYMCE-13100
- Views that keep the toolbar now also keep the statusbar visible. #TINYMCE-14920
