## 8.11.0 - 2026-11-25

### Added
- New `onDoubleClick` option for toolbar toggle buttons, called when the button is double clicked. #TINYMCE-15104
- The `table_appearance_options` option now also accepts an object with `cellspacing`, `cellpadding`, `borderwidth` and `caption` keys, to hide individual fields in the Table Properties dialog. #TINYMCE-11998

### Improved
- Inserting an accordion at the end of the content now adds an empty paragraph after it, so the caret can be placed below the accordion. #TINYMCE-9955
- Changing the width in the Cell Properties dialog now uses the inline column resize logic to ensure the table width does not change. #TINYMCE-13193

### Fixed
- Dialogs opened inline from the toolbar scrolled out of view with the toolbar instead of staying at the top of the window. #TINYMCE-10480
- Integrations moving focus between inline editors could revert focus back to the previous editor. #TINYMCE-14953
- Removing bold or italic from a nested list item no longer leaves it styled through inheritance from its parent list item. #TINYMCE-14935
- Resizing the sidebar in a right-to-left editor resized it in the opposite direction to the drag. #TINYMCE-14904
- Clicking to the left or right of an accordion did not place the caret before or after it. #TINYMCE-9955
- It was not possible to place the caret between two adjacent accordions using the arrow keys. #TINYMCE-9955
- Pressing Delete or Backspace did not remove an empty block before or after an accordion. #TINYMCE-9955
- Focusing the editor with `scrollToSelection: false` still scrolled on Safari 26 and later. #TINYMCE-15097
- The `editor.insertContent` API removed inline formatting when the selection covered the entire block content and the content was wrapped in an inline format element. #TINYMCE-11317
- Formatting text in Firefox 158 and later removed quotes around font names that contain spaces. #TINYMCE-15130
- The `ToggleView` command ignored the `skip_focus` argument. #TINYMCE-15108
- Pressing Tab could move focus into a disabled editor, which showed no focus indicator. #TINYMCE-13514
- Image resize handler was not shown on hybrid devices with both a touchscreen and a mouse or trackpad. #TINYMCE-14668
- Saving the Table Properties dialog with `table_appearance_options` hiding fields no longer removes the table's existing cell spacing, border width or caption. #TINYMCE-15197
